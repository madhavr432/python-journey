## 📌 Overview

Python Journey is a structured collection of programming exercises and practical notebooks created to build a strong foundation in Python and prepare for further work in Data Science, AI, and Machine Learning.

The repository progresses from basic syntax and control flow to data structures, OOP, file operations, numerical computation, and exploratory data analysis.

Rather than focusing only on theory, I use runnable examples and assignments to practise concepts and understand how they apply to real programming problems.

## ✨ Key Highlights

- **Structured learning path:** Topic-wise progression from core Python to data analysis.
- **Hands-on practice:** More than 100 practice assignments and exercises, as documented in the repository.
- **Object-oriented design:** Classes, encapsulation, abstraction, inheritance, and polymorphism.
- **Numerical computing:** NumPy arrays, vectorization, broadcasting, normalization, sigmoid functions, and Mean Squared Error (MSE).
- **Data analysis:** Pandas DataFrames, data cleaning, aggregation, merging, pivot tables, and feature extraction.
- **Real-world practice:** Product-management simulation, dataset exploration, and file-processing exercises.
- **Workflow automation:** A Windows batch script for streamlining Git commits and pushes.

## ⚙️ Git Automation

The repository includes `prime_push.bat`, a Windows batch script designed to streamline routine Git operations during practice sessions.

**Implemented capabilities**
- Configures UTF-8 terminal encoding.
- Checks Git availability and repository initialization.
- Detects the currently checked-out branch.
- Pulls remote changes using rebase before pushing.
- Accepts a custom commit message or generates a timestamped message.
- Records push errors in `git_error.log`.

**Example generated commit message**

```text
Auto-upload on 2026-08-18 10:00:00
```

**Usage**

Run the batch script from your repository directory in Windows Command Prompt or PowerShell:

```bat
prime_push.bat
```

Review the script before running it. Automatic Git synchronization can still encounter conflicts, and rebasing may require manual resolution.

## 🚀 Getting Started

### Prerequisites

- Python 3.9 or a compatible Python version
- Git
- Jupyter Notebook or JupyterLab for notebook exercises

### 1. Clone the repository

```bash
git clone https://github.com/madhavr432/python-journey.git
cd python-journey
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

**Windows — Command Prompt**

```bat
venv\Scripts\activate
```

**Windows — PowerShell**

```powershell
.\venv\Scripts\Activate.ps1
```

**macOS / Linux**

```bash
source venv/bin/activate
```

### 3. Install the main dependencies

```bash
python -m pip install --upgrade pip
pip install numpy pandas matplotlib jupyter
```

Some exercises may use Python's standard library and require no additional installation.

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebooks in the `numpy/` or `pandas/` directory and execute their cells.

For standalone Python exercises, run the relevant script from the repository directory:

```bash
python day2/datatype.py
```

Replace the example path with the script you want to practise.
